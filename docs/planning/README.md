# Planning 文档索引

## Status

Active.

## Purpose

`docs/planning/` 记录已确认阶段边界下的可执行任务拆分、依赖关系、验证路径和后续执行前置条件。

本目录不替代 `docs/phases/` 的阶段需求，也不替代 `docs/design/` 的系统设计。需求范围以 `docs/requirements.md` 和 `docs/phases/` 为准；实现任务边界以本目录的 planning 文档为准。

## Documents

- `phase0-poc-plan.md`：完整 Phase0-PoC 的当前执行计划、Phase0a bootstrap 状态、IR blocker 和后续任务顺序。
- `phase0a-poc-tasks.md`：Phase0a-PoC 的任务拆分、依赖关系、验证路径和正式样例接入前置条件。
