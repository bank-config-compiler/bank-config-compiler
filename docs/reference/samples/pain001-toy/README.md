# pain001-toy Reference Sample

## Status

Reference / Toy sample. Not golden sample.

## Purpose

本目录保存从 `tmp/samples` 迁移来的 `pain.001` toy sample，用于说明 Raw Docs、DocIR、SchemaIR、Import JSON 之间的关系。

该样例不满足正式 MVP golden sample 要求：

- 字段数量不足 20 个。
- 不是用户提供的真实脱敏银行接口文档。
- SchemaIR 只覆盖部分 DocIR 字段。
- Import JSON 不是已确认的真实银企直连导入格式。

- `raw-doc.md`
- `docir.md`
